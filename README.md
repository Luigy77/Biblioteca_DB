# Trabalho - Biblioteca com SQLite

## Arquivos

- `main.py` - menu principal da aplicação.
- `biblioteca.py` - criação das tabelas e funções de cadastro/listagem.
- `biblioteca.db` - banco SQLite criado automaticamente na primeira execução.

## Como executar

Abra o terminal na pasta do projeto e execute:

## python main.py

As tabelas são criadas automaticamente quando o programa é iniciado.

## Tabelas

- `usuarios`
- `autores`
- `editoras`
- `livros`
- `emprestimos`
- `emprestimos_livros`
